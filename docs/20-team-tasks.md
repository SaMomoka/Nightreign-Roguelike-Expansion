本次为每个可选效果建立两个独立 Mod 定义及确定性池，第二、第三次出现改用不同 ID；独立 compatibilityId / exclusivityId，其余文字和游戏效果字段逐字段核对不变。自定义 ID 从 1800000000 分配，构建检查碰撞。不同效果之间原有冲突仍保留。深夜正面及负面重复均覆盖。

验证：122 项 unittest、validate、1,859 组实际目录重复配方编码和资源往返检查通过。候选包 full_relic_20261024_155430_b4d2db。尚未确认成品保留、重启保留及数值叠加，不能称为实机修复完成。

兼容性：新成品引用 Mod 自定义词条，须保留对应包加载；不能沿用原生词条“撤除生成补丁仍有效”的结论。ID 映射按当前固定目录生成，后续目录更新必须保留映射或迁移，禁止直接套用旧测试存档。本次使用新的隔离副本，不修改正式存档。

下一次集中实测：购买三条相同提升血量上限，查看成品三行；记录装备前后及卸下数值，重新进入后确认词条保留。显示三行与实际叠加分别记录；既有丢失的成品需重新制作。
