# 训练场潜在能力自选测试与首批新增数值 Buff

## 范围与状态

用户于 2026-10-24 要求从遗物制作进入下一个功能：新增局内潜在能力，并在训练场通过自选候选和主动掉落降低测试成本。本次为首批六项新增数值定义及测试入口，不代表任务书全部 15 类机制已完成实装。15 类设计仍保留于 data/buffs.json；复杂触发、联机、动态构筑权重另行接入。

分支 codex/training-buff-selector；本地基准 e75e431，远端基准 977997b。基于已通过用户重复词条测试的遗物包构建，保留小壶制作与原训练设置。新副本与之前测试存档分离。

构建与 129 项测试通过，训练场掉落、选择和效果待实机。底层 Force Character Treasure 指令存在不等于其在新增载体上必然生成潜在能力，报告明确保留这一验证项。

## 游戏内流程

训练场训练用品箱交互（选择武器、道具的入口），以及原训练设置交互 → 原训练用品／设置 / NRE 潜在能力测试 / 离开。首选从训练用品箱进入，不要求在菜单中寻找名为“变更训练设置”的列表项。

测试菜单五项：候选 1、候选 2、候选 3、生成潜在能力、返回。每个候选可选六种新增 Buff，翻页可选六种原生对照。默认候选为新增生命、FP、精力。后台准备三个确定性奖励池后，原生脚本在训练设置交互附近请求生成一份奖励，仍由游戏负责拾取与选择。点击生成不直接授予 Buff，也不扣除暗痕。

玩家交互完全在游戏内。后台适配器仅修改三个 Mod 专用 ItemTableParam 行的 itemId，并回复专用菜单变量；不执行远程代码，不直接写库存、货币或存档。普通 ItemTableParam 的重复行 ID 合法；只要求三个专用池各有一个唯一行。

取消选项保留当前进程草稿。新进程恢复默认候选。允许重复候选用于压力测试，但游戏是否合并重复奖励仍需观察。每次领取后再生成，避免尚未领取的奖励是否动态引用已改池尚不明确的问题。

## 首批新增 Buff

| 新增候选 | 当前效果 | 原生对照 | 测试要点 |
| --- | --- | --- | --- |
| NRE 生命上限 +5% | maxHpRate=1.05 | 原生生命 +10% | 同角色同等级最大生命；当前生命另记 |
| NRE FP 上限 +5% | maxMpRate=1.05 | 原生 FP +10% | 最大 FP 与施法消耗对照 |
| NRE 精力上限 +5% | maxStaminaRate=1.05 | 原生精力 +10% | 最大精力与同动作次数 |
| NRE 物理攻击 +3% | physicsAttackRate=1.03 | 原生物理攻击 +6% | 同武器、同目标、同动作伤害 |
| NRE 物理承伤 -4% | 四种物理 DamageCutRate=0.96 | 原生物理承伤 -12% | 同物理攻击实际损失生命 |
| NRE 属性承伤 -4% | 魔力/火/雷/圣 DamageCutRate=0.96 | 原生属性承伤 -12% | 同属性伤害；不推断异常抗性 |

设计动机：以较小的单次增量形成多次选择的成长节奏，并保留原生对照排查训练场是否支持永久 Buff 路径。这是初始平衡数值，不是已经确定的最终强度。显示数值和实际修改字段来自同一目录定义。

新增完整链：自定义 Goods → 自定义 PermanentBuff → 自定义 SpEffect。不是修改原生所有来源的同名 Buff。继承原生持续、存储和分类字段；当前重复获得的加算/乘算/覆盖、死亡与远征清理依赖原生行为，尚未实现任务书的独立层数上限或统一加算。不能提前标记叠层规则验收通过。

### 首次落点修正（实测无效，已撤除）

训练用品箱入口及生成已经由用户确认，但固定坐标掉落在内部，无法靠近交互。改为每次请求时先执行 Nightreign EMEVD 2004[42]：仅移动 Mod 载体 10000980 到本地玩家 10000（Character=2、dummypoly=-1），并复制玩家所处地面；等待两帧后执行掉落。玩家本身不被传送。当时预期原固定位置只作初始停放点，但后续实测证明奖励仍出现在原处；该方案无效，现已撤除。


### 固定空地落点（第二轮修正）

用户反馈移动到玩家位置后仍不可交互；只读游戏截图确认奖励在帐篷内部桌架后。移除未生效的载体传送路径，不宣称定位了引擎内部原因。改在 MSB 原件中，以训练靶 10000404、10000405 的已知位置中点设置载体，Y 取较高靶点 +0.25，构建后验证坐标往返。实际落点约 (38.532, 10.123, 103.422)，位于帐篷外训练区。可拾取性仍需实机确认。
