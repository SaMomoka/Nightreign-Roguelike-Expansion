# 小壶自造遗物：类型、颜色与原生分类

## 2026-10-24 改动

用户要求将四个编号预设入口改为自由制作购买，并增加颜色选择和类似遗物仪式的筛选。本轮基于本地 a03ce3f、远端 main 6614594，分支 codex/relic-colors-filters。

小壶 → NRE 遗物制作现在仅有“普通遗物”“深夜遗物”“返回”。进入后有六个选项：词条 1、词条 2、词条 3、颜色、确定制作（1 暗痕）、返回。默认绿色，颜色页可选红、蓝、黄、绿。每种类型保留一份本次游戏会话内的草稿；制作后可以继续改配方再购买，不再把编号当作可持有遗物数量限制。

颜色修改保留三条词条及其负面绑定，并使旧制作请求失效。深夜需要负面的正面词条仍在选定负面后才提交，取消保留原组合，换成无需负面的正面会清除该槽旧负面。

## 筛选方式与 UI 边界

词条按“分类 → 子分类 → 同类词条 → 具体等级／变体”查找。分类、子分类和族关联直接从当前固定版本的 AttachEffectParam.attachFilterParamId、AttachEffectFilterParam、AttachEffectFilterSubCategoryParam、AttachEffectFilterCategoryParam 取得，文字来自已校验的原生 FMG。不是用中文关键词猜分类。

角色专属可以继续选角色，武器专属继续选武器类型，通用继续选能力值、攻击力、恢复等；负面继续选能力值、减伤率、行动等。原生“全部”类别在本菜单标成“通用”，避免误以为它包含角色和武器专属。同族多个等级合在一个入口内，显示数量。单个候选直接选择，多候选进入具体列表；每页最多六个内容项，另有上下页及返回，翻页显示页码。不适用于当前类型的空分类不显示。

未关联有效筛选数据的候选进入“其他／未分类”，不会静默丢失。目录范围仍为普通 406、深夜正面 326、负面 24。原生获得进度的显示事件旗标没有用于隐藏自由制作候选；职业效果自身的职业限制继续保留。

本轮复用了遗物仪式的筛选数据与文字，**没有直接复用遗物仪式的格子界面、复选框、多条件交集或搜索输入框**。已验证的接入仍是小壶原生 ESD 对话菜单；整块筛选面板的打开与结果回传接口未确认，不编造接口或把分级菜单宣称为原版面板。

## 颜色与制作实现

为普通和深夜各准备四个固定颜色载体，复用已有自定义行 9000000–9000007 及商店行 1900200000–1900200007。普通模板为 102、111、120、129；深夜模板为 2000002、2000102、2000202、2000302。构建时检查每个模板的 relicColor、isDeepRelic 与图标。物品名称为相应颜色的自造遗物。

运行时只改变所选载体的六个效果池字段，颜色和图标不做运行时重写，避免改颜色同时改动已有成品的共用模板。扣费、发放和库存上限仍由原生商店负责。八个载体是实现细节，不是八件购买上限。重复制作为不同实例及已购物品的稳定性仍需实机确认，不能以程序结构代替结果。

内部协议保留旧 0/2 作为普通/深夜路由，1/3 不再生成 UI；旧纯逻辑四草稿接口仅作开发兼容。新的颜色选择操作为 600/602，颜色文字查询为 700/702，均为本项目后台协议号，非新增游戏原生函数。

加入两份 item_dlc01 文本资源、颜色模块散列检查、原生筛选导出工具。改变了旧实验行的类型及颜色用途，**只使用本次新建的隔离测试存档**，不要把旧实验自造遗物存档换成本包使用。正式存档不参与测试。

## 2026-10-24 追加：允许重复词条

用户明确要求允许同一遗物出现多个完全相同词条。自造编辑器现允许两个或三个槽选择相同正面；深夜负面也可重复。每槽的正负绑定独立保留，取消及替换一个槽不会清除其他槽的相同词条。

选择与制作检查不再拒绝重复 ID；原生兼容／排他分组检查仅对不同 ID 执行，避免相同词条被分组检查再次挡住。不同词条之间原有分组冲突、普通／深夜分类、三槽完整性、所需负面及过期请求校验仍保留。菜单无需额外开关，直接在多个槽选择同一项即可，价格仍为 1 暗痕。

传给原生成品参数的三条正面及三条负面不会去重。自动检查覆盖三条相同正面、三组相同正负组合、替换单槽、取消、请求路由及六个实际写入字段。此改动允许制作请求携带重复词条，不能证明游戏一定保留重复项或数值按次数叠加；购买、展示、保存与实际效果仍待实机确认。旧有限候选配置器的合法性规则未改动。
