# 游戏内四遗物制作编辑器

本版本按用户要求把小壶入口扩展为两个普通遗物、两个深夜遗物编辑页。它是新的实验版，旧版预设购买菜单的实机通过结论不自动覆盖本版本。

## 操作

启动根目录 `启动遗物制作实验包.cmd`，进入独立测试存档，与小壶交互，选择“NRE 遗物制作”。四个入口均有五项：

1. 词条 1：打开候选列表。
2. 词条 2：打开候选列表。
3. 词条 3：打开候选列表。
4. 确定制作：选满三条后打开价格为 1 暗痕的原生商品页，确认购买才扣费并获得遗物。
5. 返回：回到四遗物入口列表。

选词条后返回该编辑页，显示当前选择。候选页可清除该条或返回。同一件遗物不允许选择重复词条。未选满时点第四项不会进入购买，也不会扣费。

当前草稿仅在该件编辑流程内保留；返回四遗物入口再进入时重新选择。四个入口不会串用草稿。已经购买的物品不受草稿清除影响。

## 当前候选范围

普通遗物三个位置均可选择生命力、集中力、耐力、力气、灵巧、智力各 +1，合计 20 种不重复三词条成品。

深夜遗物第一条可选择物理、魔力、火属性攻击力提升 +3，并绑定“力气、智力降低”负面词条。第二、三条可选择毒、出血、睡眠、咒死、腐败、冻伤、发狂抗性 +1，合计 63 种成品。负面绑定来自本机原生槽位规则，不能在本版本移除。

这不是全词条库；当前采用已核对原生池归属的候选子集。制作运行时全部使用游戏原生菜单及商店，不需要外部配置窗口。

## 构建与验收

运行 `构建遗物制作实验包.cmd` 可生成新包；构建不会自动启动游戏。开发检查：

```powershell
python -m unittest discover -s tests -v
python tools/validate.py
python tools/check_relic_editor.py
```

本轮 84 项单元测试通过；资源读写回读、原参数行保留、原 ESD 恢复一致性、菜单等待循环和非法制作拒绝检查通过。结果见 `tests/ingame/RELIC-EDITOR-build.json`。四入口包含 3658 个页面、15125 个新增状态；加载性能、菜单显示、新遗物定义、购买扣费和重复购买库存行为尚待实机验证。

原生商店承担扣费和发放，不使用自行猜测的运行时函数。新遗物采用独立参数定义，**购买后必须继续加载本 Mod 才能可靠识别这些定义**；不能套用旧版原生遗物模板撤补丁后的持久性测试结论。本版本不提供原版回滚入口，仅使用独立测试存档。

普通/深夜难度配额尚未接入本编辑器。多人未验收。包中保留分层三选一奖励参数，其实机验证仍暂缓。

## 批量实机验收

检查四入口、五选项、候选选择后标签更新、重复过滤、未选满和取消不扣费；普通与深夜各制作一件，确认扣除 1 暗痕、词条正确、可装备及卸下恢复；同一组合再买一次检查库存行为。正常退出后用同一制作包重启，检查新遗物保留。记录实际结果后再更新游戏验收状态。
