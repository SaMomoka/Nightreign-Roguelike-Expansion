# 全量原生遗物编辑器

## 状态

全量游戏包已构建并启动隔离测试。普通 406 条、深夜正面 326 条、负面 24 条已接入原生分页菜单；其中 49 条深夜正面要求选择负面。构建检查与自动测试通过，**完整游戏内制作、同一入口连续制作不同配方及重启持久性仍待实测**。上一版小词条集的制作通过不替代这些验证。

双击 `构建全量遗物制作实验包.cmd` 构建，双击 `启动全量遗物制作实验包.cmd` 启动。旧版入口保留，两个版本使用不同的隔离存档。进入小壶商人的“NRE 遗物制作”，首次后台连接可能稍有等待。

## 游戏内使用

两个普通、两个深夜入口各有三个词条选择、制作和返回。候选每页六项，提供翻页和返回。四份草稿在本次游戏进程内独立保存；关闭游戏后不保存未制作草稿。

需要负面的深夜正面会继续打开负面选择；取消则保留旧组合。换成无需负面的正面会同时清除旧负面。未选满、重复词条、原生兼容或排他分组冲突会拒绝制作。职业专属效果仍受原生职业限制。

确定制作后进入对应原生商店，标价 1 暗痕。扣费和发放由游戏处理；后台模块只准备所选配方。尚未验证的购买结果不得标记为成功。

## 实现及边界

所有玩家交互均在原生对话和商店内。启动器同时运行无窗口本地 Python 模块，通过四个原生 WorkValue 传递请求并在内存中准备本 Mod 自有的四行参数。没有外部配置窗口，也不直接修改货币或存档。

只读探针已在隔离游戏中找到唯一连续的四个菜单变量，且回读找到 83 行旧测试参数。该证据证明定位方法可行，不能单独证明完整运行时交互通过。

完整包使用 12,223 个新 ESD 状态、每语言 5,405 条文本，避免枚举三词条的全部组合。四个成品使用项目自定义行 9000000–9000003；仅修改这四行中六个效果池字段，其他字节不变。写入前校验进程、隔离存档日志、资源散列、参数行内容与地址范围，写入后回读。连接或校验失败时不会继续正常制作流程。

运行时依赖本包和本地后台模块；未验证无 Mod 持久性、多人、地图切换后的重新连接和英文界面。再次制作是否影响先前购买的实例，需实机检查。原游戏资源只读，正式存档不用于测试。

## 证据和检查

`local/full-relic-package.json` 定位最新完整包。包内 `full-build-report.json` 为构建证据，`runtime.log` 为后台请求记录，均不等价于用户实机验收。`tests/ingame/RELIC-FULL-CATALOG.json` 是较早的目录和纯逻辑检查记录，其 runtime_unbound 字段描述该检查阶段。

执行 `python -m unittest discover -s tests -v`、`python tools/check_full_relic_selection.py` 和 `python tools/validate.py`。候选校验覆盖全部 1,176 个要求负面的正负配对；不代表任意三个配对组合都兼容。

接口事实参考 [ESDLang 的 Talk 定义](https://github.com/thefifthmatt/ESDLang/blob/master/dist/ESDScriptingDocumentation_Talk.json) 与 [ESD 字节码说明](https://gist.github.com/JKAnderson/e3fd38d4efd5f3350e13a613319b8bed)。本机用户提供的 CT 仅作为参数定位事实参考，没有执行 CT 或复制其实现。所有生成游戏资源留在 ignored 的 local 目录。
